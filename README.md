# Co-Bo 🌳

**Tree Test Tool per il Comune di Bologna**

Strumento di tree testing sviluppato per valutare l'architettura informativa dei servizi digitali del Comune di Bologna.

---

## Cos'è un Tree Test?

Il tree test è una tecnica di UX research che valuta la trovabilità dei contenuti in una struttura gerarchica. I partecipanti navigano un'alberatura testuale (senza UI) per completare task specifici, rivelando problemi di categorizzazione e labeling.

---

## Il progetto

Ho progettato e sviluppato questo tool per condurre sessioni di tree testing con cittadini e stakeholder, nell'ambito della riprogettazione dell'architettura informativa del sito comunale.

### Features
- Navigazione ad albero interattiva
- Tracciamento del percorso utente
- Raccolta dati per analisi quantitativa
- Setup task personalizzabili

---

## Stack

`HTML` · `CSS` · `JavaScript`

Progetto realizzato come parte di un'attività di Qualitative Research e UX Design per la Pubblica Amministrazione.
